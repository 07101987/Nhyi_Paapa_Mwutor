# Owrafix Learning App - iPad Installation Guide

This app is ready for iPad as a Progressive Web App (PWA). That means it can sit on the iPad Home Screen like a normal app and work offline after it has loaded once.

## What You Need

- An iPad
- Safari browser on the iPad
- Your GitHub Pages link for the app
- Internet for the first installation only

## Important

iPads do not install Windows `.exe`, Linux packages, or normal ZIP app folders. For iPad, use the Safari **Add to Home Screen** method.

## Install on iPad

1. Upload or push the latest app files to GitHub.
2. Make sure GitHub Pages is turned on for the repository.
3. On the iPad, open Safari.
4. Go to your app link, for example:

   `https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/reset-cache.html`

5. Wait for the app to open.
6. Tap the Safari **Share** button.
7. Tap **Add to Home Screen**.
8. Name it:

   `Owrafix`

9. Tap **Add**.
10. Open the new app icon from the iPad Home Screen.

## Make It Work Offline

After adding it to the Home Screen:

1. Open the app while connected to the internet.
2. Visit Learn, Exams, Worksheets, and Parent sections once.
3. Wait a few seconds.
4. Turn off Wi-Fi and open the app again from the Home Screen.

The lessons, quizzes, worksheets, badges, progress, and dashboards are stored on the iPad.

## Updating the iPad App

When you make changes:

1. Push the new files to GitHub.
2. On the iPad, open:

   `https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/reset-cache.html`

3. The reset page clears the old offline copy and opens the new version.
4. Open the Home Screen app again.

## Best Setup for Nkunim

- Keep the app icon on the first Home Screen page.
- Open it once before school or travel so it refreshes.
- Use the Parent Dashboard weekly to check progress.
- Use Exams for revision before school tests.
